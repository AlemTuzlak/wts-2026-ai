Copied from `threejs-presentation/template`. Do **not** fork nav, painter core, or timer unless a talk feature requires it. Small extensions already exist. Keep them.

### Files you edit

| File                      | Job                                                                                                |
| ------------------------- | -------------------------------------------------------------------------------------------------- |
| `src/talk.js`             | Slide list, timer, theme, code lines, cameras                                                      |
| `src/scene/layout.js`     | Colors, island positions, camera waypoints                                                         |
| `src/scene/World.jsx`     | Lights + fog + composes Shack and MapWorld                                                         |
| `src/scene/Shack.jsx`     | Interior, window, table, mini-map, title board, close logo                                         |
| `src/scene/MapWorld.jsx`  | Sea, islands, dashes, boat, dock, drawbridge, buoys, giant sheet                                   |
| `src/scene/Label.jsx`     | Canvas sprite labels (no drei Text — drei Text suspended the canvas)                               |
| `src/scene/Surface.jsx`   | Catalog canvas texture. Accepts position / rotation / scale / visible                              |
| `src/catalog/paint.js`    | Title, statement, code, punch. Loads Bricolage + Inter. Supports `linesSteps` and `highlightSteps` |
| `src/scene/CameraRig.jsx` | Lerps to `slide.cameras[step]` or `slide.camera`                                                   |
| `src/App.jsx`             | Canvas, Suspense around World, sky color from shack vs map                                         |
| `src/store.js`            | Zustand. Reads `?slide=` on init. Do not break this                                                |
| `src/nav.js`              | Zurich keys. Do not change                                                                         |
| `src/hud/Hud.jsx`         | Counter + timer                                                                                    |

### Two spaces

1. **Shack** at the origin (`y ≈ 0`). Slides: `title`, `the-map`, `close`.
2. **Map sea** at `MAP_Y = -50`. All other slides.

The dive from table to islands is a camera lerp through empty space. That is the “enter the map” beat. Keep it.

`shackSlides` in `layout.js` drives sky color, fog, and lights.

### Hero surface

- Shack title/close: a wooden board in front of the window, `Surface` with form `title`.
- Map catalog (statements + code): giant sheet at `sheet.position` `[0, -41, 3]`, scale 6. Hidden when `slide.form === 'punch'`.
- Punch slides: hide the sheet. The sea is the slide.
- `the-map`: 3D mini islands on the table. Catalog form is `statement` for `?flat` only. Do not put Surface on the table for that slide.

### Do not use

- `@react-three/drei` `Text` or `useTexture` **without** `Suspense`. They suspend the whole Canvas. The first screenshots were a blank sky + HUD. `App.jsx` now wraps `World` in `<Suspense fallback={null}>`. Labels use `Label.jsx` canvas sprites. The close logo uses `TextureLoader` in `useEffect`.
